# HashQL

A lightweight CSV-based database management system implemented in C++.

## Goal

HashQL is a command-line database system designed to demonstrate
C++ programming, OOP, file handling, data structures, and database
management concepts.

## Planned Features

- Create CSV database files
- Add records
- View records
- Search records
- Update records
- Delete records
- Delete database files
- Command-line interface
- Persistent CSV storage
- Data structure based indexing (future)

## Commands

CREATE <filename>
ADD <filename>
SHOW <filename>
SEARCH <filename> <id>
UPDATE <filename> <id>
DELETE <filename> <id>
DELETE_FILE <filename>
HELP
EXIT
